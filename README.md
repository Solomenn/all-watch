# All-Watch

面向 iPhone、OPPO Watch X3 Mini 与 Windows 的个人跨设备工作台。

## 产品目标

让三个设备访问同一份个人数据，而不是维护三套互不相通的应用。

第一阶段先完成 **Todo 清单**：

- iPhone：完整管理任务；
- Windows：完整管理、编辑和整理任务；
- OPPO Watch X3 Mini：快速查看、完成、延后和新增任务；
- 三端共享同一份数据，支持离线操作、恢复联网后同步和冲突处理。

后续再扩展笔记、计时器、个人记录等模块。第一阶段不提前扩张为大而全的 Personal Hub。

## 阶段 0：Bluetooth Network Relay POC

用户已观察到：OPPO Watch X3 Mini 不连接 Wi-Fi 时，仍可通过与 iPhone 的蓝牙连接使用部分联网功能。

OPPO 健康 App 的隐私政策也描述了穿戴设备通过蓝牙数据通道请求健康 App 转发网络请求的机制，并举例说明小布助手和天气服务。

**尚未确认：普通第三方手表 APK 能否使用同一条网络通道。**

因此先做最小验证，不先开发完整清单界面。详见 [Bluetooth Network Relay POC](docs/bluetooth-network-relay-poc.md)。

## 架构原则

1. **数据归用户控制**：提供完整导出与备份能力，不把数据锁死在单一客户端。
2. **先离线可用**：本地操作先落盘，网络恢复后再同步。
3. **云端统一，多端轻客户端**：云端负责跨设备数据一致性；手表只承担轻量交互。
4. **通信方式可替换**：蓝牙代理、手表 Wi-Fi、手机中继和云端 API 分层，不把产品绑死在某个厂商私有协议上。
5. **证据驱动**：未在真实设备验证的能力必须标为假设或待验证。
